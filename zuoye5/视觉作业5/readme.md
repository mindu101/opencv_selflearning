### 核心思路
1. 进行了高斯模糊，开运算，闭运算，来尝试消除光晕，以此来提高hsv范围的准确性；
2. 根据颜色的hsv范围，来制造掩膜，然后得到二值化的图。
3. 用findcontours得到轮廓，然后遍历每一个轮廓，把每一个轮廓的面积-标号的pair给塞进一个vector容器，利用sort函数排序，排序得到了面积的降序排列，之所以需要这一步操作，是为了方便获取最大的两个面积的值，为了排除一些明显错误的矩形，根据灯光条的长宽比，做了一个if else，进行排除；
4. 排序之后，我选择写了一个for循环，因为显然最大的两个面积是灯条的，我遍历了j=0,j=1,就把两个灯条处理完成了，用点的连线很容易就搞出来矩形。
5. 基本完成，得到一下两个轮廓的中点，然后做连线，就出来了中点坐标。
### 使用指南
1. choose=1为红，choose！=1为蓝
2. 把videoCapture 里改成videoCapture i(0)就能变成摄像头测试了
3. 本程序未设计程序内退出，只能杀进程。
### 不足之处
1. 无法面对复杂的灯光情况，灯光所散发的光晕会导致识别出错
2. 蓝色灯光的hsv范围并不理想，识别蓝色灯光的效果明显差于红色灯光。
3. 当摄像头距离较远的时候，无法实现准确识别
4. 摄像头距离某一个灯光口特别近时，易出错
