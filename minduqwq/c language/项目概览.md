## 项目概述
本项目是一个基于OpenCV库实现的图像处理系统，能够完成图像的多种基础与高级处理操作。系统采用模块化设计，支持灰度化、模糊滤波、边缘检测、亮度调整、图像翻转等功能，并提供了灵活的组合处理能力。

## 功能特性

### 基础层功能（已完成）
- ✅ **图像读取与基本信息输出**：读取BMP/JPEG图像，输出图像类型和分辨率
- ✅ **灰度化处理**：将24位彩色图像转换为灰度图像
- ✅ **图像写入**：将处理结果保存为图像文件
- ✅ **基础输出**：实时显示处理进度和图像基本信息

### 进阶层功能（已完成）
- ✅ **模糊滤镜**：基于3×3邻域的加权平均实现图像模糊
- ✅ **边缘检测**：使用Canny算子进行边缘检测
- ✅ **组合处理**：支持灰度化+模糊、灰度化+边缘检测等组合功能

### 拓展层功能（已完成）
- ✅ **亮度调整**：通过HSV色彩空间的V通道调整图像亮度
- ✅ **图像翻转**：支持水平和垂直方向的图像翻转
- ✅ **处理效果对比**：支持选取10×10像素区域进行前后对比

## 核心功能说明

### 1. 图像读取与基本信息
```cpp
pic1 = imread("../picture/t1.jpg");
cout << "图像类型: " << pic1.type() << endl;
cout << "长: " << pic1.cols << " 宽: " << pic1.rows << endl;
```

### 2. 灰度化处理
使用OpenCV的cvtColor函数将BGR图像转换为灰度图像：
```cpp
cvtColor(pic1, pic1_gray, COLOR_BGR2GRAY);
```

### 3. 模糊滤波
使用3×3卷积核进行图像平滑处理：
```cpp
blur(pic1, mohu, Size(3, 3));
```

### 4. 边缘检测
使用Canny算子进行边缘检测，阈值范围为1-100：
```cpp
Canny(pic1, pic_can, 1, 100);
```

### 5. 亮度调整
通过HSV色彩空间调整图像亮度：
```cpp
cvtColor(pic1, pic_hsv, COLOR_BGR2HSV);
split(pic_hsv, hsv);
hsv[2].convertTo(hsv[2], -1, 1, 100);  // V通道增加100
merge(hsv, pic_hsv);
cvtColor(pic_hsv, pic_hsv_BGR, COLOR_HSV2BGR);
```

### 6. 图像翻转
支持水平和垂直方向的翻转：
```cpp
flip(pic1, pic_0, 0);  // 垂直翻转
flip(pic1, pic_1, 1);  // 水平翻转
```

### 7. 像素对比功能
允许用户选择10×10像素区域进行前后对比：
```cpp

```

## 使用方法

### 环境要求
- C++编译器（支持C++11及以上）
- OpenCV 4.0或更高版本
- CMake
- 

### 编译运行
1. 确保已安装OpenCV库
2. 编译程序：
```bash
g++ -o image_processor image_filter_project.cpp `pkg-config --cflags --libs opencv4`
```
3. 运行程序：
```bash
./image_processor
```

### 操作说明
1. 程序会自动处理`picture/t1.jpg`图像
2. 所有处理结果将保存到`save/`目录
3. 运行时会提示输入坐标，输入`-1 -1`退出程序

## 输出文件说明

程序会生成以下8个处理结果文件：
1. **灰度图0.jpg** - 原始图像的灰度版本
2. **边缘1.jpg** - 边缘检测结果
3. **hsv2.jpg** - 转换到HSV色彩空间的结果
4. **更改亮度3.jpg** - 亮度调整后的图像
5. **上下反转4.jpg** - 垂直翻转的图像
6. **左右反转5.jpg** - 水平翻转的图像
7. **灰度图_模糊6.jpg** - 灰度图像经过模糊处理
8. **灰度图_边缘7.jpg** - 灰度图像经过边缘检测

## 技术特点

1. **模块化设计**：每个功能独立实现，便于维护和扩展
2. **内存高效**：使用OpenCV的Mat类管理图像数据
3. **用户交互**：支持交互式像素对比功能
4. **批量处理**：自动保存所有处理结果
5. **错误处理**：基本的边界检查和错误预防

## 注意事项

1. 确保输入图像路径正确
2. 保存目录需要预先创建或有写入权限
3. 像素对比功能输入的坐标应在图像范围内
4. 亮度调整参数可根据需要修改
